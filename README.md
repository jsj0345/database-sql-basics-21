# Database SQL Basics 21

MySQL을 사용하여 관계형 데이터베이스의 SQL 활용 방법과 주요 개념을 학습하고, 예제 쿼리와 문서로 정리한 저장소입니다.

`JOIN`, 서브쿼리, `UNION`, `CASE`, 뷰를 활용한 데이터 조회부터 인덱스, 데이터 무결성, 트랜잭션까지 학습했습니다.

## 학습 목적

여러 테이블에 나누어 저장된 데이터를 조회하고, 조건에 맞게 가공하는 SQL 활용 방법을 이해하기 위해 정리했습니다.

인덱스와 실행 계획을 통해 조회 성능을 살펴보고, 제약 조건과 트랜잭션을 통해 데이터의 일관성을 유지하는 방법을 이해하는 데 중점을 두었습니다.

## 학습 내용

- `INNER JOIN`, `OUTER JOIN`을 활용한 테이블 결합
- 서브쿼리, `UNION`, `CASE`, `VIEW` 활용
- 인덱스와 `EXPLAIN`을 통한 조회 성능 확인
- 기본 키, 외래 키 등 제약 조건을 통한 데이터 무결성 관리
- 트랜잭션의 ACID 특성과 격리 수준

## 학습 포인트

- JOIN의 종류에 따라 조회 결과에 포함되는 행이 달라지는 이유를 학습했습니다.
- 서브쿼리의 반환 결과와 외부 쿼리와의 관계에 따라 적절한 조회 방법을 선택하는 과정을 연습했습니다.
- `UNION`, `CASE`, 뷰를 사용해 여러 조회 결과를 합치거나 데이터를 분류하고 재사용하는 방법을 익혔습니다.
- `EXPLAIN`으로 실행 계획을 확인하고, 인덱스의 구성과 검색 조건에 따라 조회 방식이 달라지는 점을 학습했습니다.
- 기본 키, 외래 키 등 제약 조건으로 데이터의 무결성을 관리하는 방법을 정리했습니다.
- 트랜잭션의 ACID 특성과 격리 수준을 학습하고, 동시 실행 시 발생할 수 있는 조회 문제를 이해했습니다.
